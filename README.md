## 🏰 Qastel
Qastel gives business, security and compliance teams one place to discover AI, set the rules and enforce them at runtime.

- **Discover**: find every AI tool in use (ChatGPT, Claude, Copilot, Gemini…) through SaaS connectors, a browser extension and a desktop agent
- **Govern**: inventory, risk scoring and EU AI Act classification for each AI system
- **Enforce**: vendor-neutral data policies applied in the browser, on the desktop and at the MCP gateway
